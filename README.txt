FOMO Analyst Agent v0.2 — PAPER TEST ONLY

1. Open index.html in a modern browser.
2. Paste your CoinGecko Demo API key (optional secondary verification).
3. Select chain and paste token contract/mint from Quant Screen or Pump Call Radar.
4. FETCH + ANALYZE.
5. Review the T0 decision, then LOCK + START WATCH.
6. v0.2 records immutable T0 and checks due horizons: 5m, 15m, 30m, 60m.
7. If the page/browser was closed, it catches up on the next open. A static HTML page cannot execute while the browser/device is fully closed.
8. Export JSON regularly. Browser localStorage is not a durable database.
